プライバシーについて

最終更新：2026年11月（日付は準備中）

このページでは、オンライン対戦で［Discordでログイン］を使ったときに、どの情報を受け取り、どう使うかを説明します。ログインしなくても、名前を入れれば遊べます。

受け取る情報

Discord から受け取るのは、次の情報だけです（Discord に求める許可は「identify」だけです）。

  • Discord のユーザー ID
  • 表示名（表示名が無い場合はユーザー名）
  • アイコンの画像を指す値（アイコンが無い場合は、Discord の標準アイコンの番号）

メールアドレス、参加しているサーバー、フレンド、メッセージは受け取りません。

使い道

対戦相手の画面に、あなたの名前とアイコンを出すためだけに使います。

置き場所と期間

  • あなたのブラウザ：ログインの証（このサイトが署名したもの）。名前・ユーザー ID・アイコンの値が入っています。30日で使えなくなります。
  • 対戦の部屋（サーバー）：対戦のあいだ、名前とアイコンの住所を置きます。部屋を閉じるときに消します（対戦が終わってから5分後。どんな場合も、部屋を作ってから6時間以内）。
  • サーバーには、Discord の情報を残しておく場所はありません。対戦の記録にも入れません。
  • Discord から受け取る鍵（アクセストークン）は、名前を読んだあとすぐに Discord へ返して無効にします。保存しません。

対戦相手に見えるもの

  • 名前とアイコンが見えます。
  • アイコンの住所には Discord のユーザー ID が入っています。相手は、その ID からあなたの Discord のアカウントを特定できます。
  • アイコンは、相手のブラウザが Discord から直接読み込みます。
  • アイコンを見せたくないときは、設定の「アイコンを相手に見せる」をオフにしてください。名前は［変更］から、登録した名前に戻せます。

ほかの人に渡すこと

対戦相手の画面に出すこと以外では、誰にも渡しません。売ったり、広告に使ったりしません。

消すには

  • ［変更］の［ログアウト］で、ブラウザから消えます。
  • Discord の「設定 → 認証済みアプリ」から、このアプリの許可を取り消せます。
  • サーバーには残っていないので、ほかに消すものはありません。
